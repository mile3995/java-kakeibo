# Java 家計簿アプリ

Java標準機能だけで作った、コンソール型の家計簿アプリです。収入と支出を記録し、一覧・削除・合計計算ができます。

## 主な機能

- 収入または支出の記録（カテゴリ、金額、任意のメモ）
- 記録日の自動設定
- 記録一覧の表示
- 番号を指定した記録の削除
- 収入合計、支出合計、差額の表示
- 数値入力の確認と、空カテゴリ・0円以下の金額の拒否

## 使用技術

- Java 8 以降
- Java標準ライブラリ（`Scanner`、`List`、`ArrayList`、`LocalDate`）
- 外部ライブラリなし

## 起動方法

JDKを用意し、このプロジェクトのフォルダーで実行します。

```powershell
javac -encoding UTF-8 -d out src/Transaction.java src/HouseholdBudgetApp.java
java -cp out HouseholdBudgetApp
```

## 使い方

メニューで操作を選びます。記録の金額は円単位で入力し、カンマは付けません（例: `1200`）。

```text
1. 記録一覧
2. 収入・支出を追加
3. 記録を削除
4. 合計を表示
0. 終了
```

## クラス構成

| ファイル | 役割 |
| --- | --- |
| `HouseholdBudgetApp.java` | メニュー、入力、一覧、削除、集計を担当 |
| `Transaction.java` | 日付・種別・カテゴリ・金額・メモを1件分のデータとして保持 |

## 実装上の工夫

- `Transaction` に記録データをまとめ、入力処理や集計処理と分けています。
- 入力された金額を `long` に変換し、数値でない場合はメッセージを出して処理を戻します。
- 集計時に記録一覧から合計を計算するため、削除後も合計が最新の一覧と一致します。
